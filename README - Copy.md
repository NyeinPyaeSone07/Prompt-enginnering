# Sales Summary & Forecasting Dashboard

## 1. Program

**Program to open:** `index.html`

Double-click `index.html` to open the Sales Summary & Forecasting Dashboard in a web browser.

Recommended browser:

* Google Chrome
* Microsoft Edge

---

## 2. How to Use the Program

### Step 1 — Open the Program

Open:

```text
index.html
```

The dashboard will open in your web browser.

---

### Step 2 — Upload the Company Sales File

In the **Data Source (Excel Upload)** section:

1. Click **Click to upload**
2. Select one of the company's sales files
3. Wait for the system to read and process the file

You can also drag and drop the file into the upload area.

Supported file types:

```text
.xlsx
.xls
.csv
```

The program is designed to process the company's cash-sales report and identify valid invoice records.

---

### Step 3 — Check the Dashboard

After uploading the file, the dashboard displays sales information such as:

* Sales to Date
* Projected Total
* Target Pace
* Daily Run Rate
* Sales vs. Target
* Forecast Range
* Invoice information

The dashboard can be used to see the current sales performance and projected month-end sales.

---

### Step 4 — Check the Sales Forecast

The **Month-End Sales Forecast & Pace** section shows the projected sales for the end of the month.

The dashboard provides:

* Conservative (Low) forecast
* Expected (Base) forecast
* Optimistic (High) forecast

The monthly target can also be adjusted by entering a new value in **Monthly Sales Target**.

---

### Step 5 — Check Invoice Information

The **Cash Sales Invoices (HS Ledger)** section displays the processed invoices.

The table includes:

* Date
* Invoice Number
* Customer Code
* Customer Name
* Salesperson
* Grand Total

You can use the search box to search for an invoice, customer, or salesperson.

---

### Step 6 — Export the Data

Click:

**Export CSV**

to export the cleaned invoice data as a CSV file.

## 7. Troubleshooting

### Dashboard does not open

Try opening `index.html` using Google Chrome or Microsoft Edge.

### Data does not appear

Check that the selected file is one of the supported formats:

```text
.xlsx / .xls / .csv
```

Then try uploading the file again.

### Want to return to sample data?

Click **Reset to Seed Data**.
